# CHIEF-PTML

Computational workflow for the analysis of molecular chirality using **CHIEF-PTML descriptors** and machine-learning models.

## Overview

This repository contains the computational code, datasets, results, figures, and supporting analyses associated with the CHIEF-PTML study of molecular chirality.

The workflow combines CHIEF-PTML descriptors with machine-learning classification models to investigate the prediction of molecular activity and the contribution of chirality-related descriptors.

The repository also contains an empirical comparison between the CHIEF-PTML approach and an **ECFP4 fingerprint with chirality information** using a Random Forest classifier under the same compound-level data partition.

## Main analysis

The main analysis evaluates seven binary classification algorithms using CHIEF-PTML descriptors:

* Random Forest (RF)
* Logistic Regression (LOGR)
* Linear Support Vector Machine (LSVM)
* k-Nearest Neighbors (KNN)
* Gaussian Naive Bayes (GNB)
* Decision Tree (DT)
* Stochastic Gradient Descent (SGD)

Model selection and hyperparameter optimization were performed using **5-fold StratifiedGroupKFold cross-validation**, with compound identity used as the grouping variable to prevent compounds from appearing in both training and validation partitions.

The primary optimization metric was the **F1 score**.

## Dataset partitioning

The dataset was partitioned at the compound level to avoid compound-level information leakage between training and test sets.

The analysis includes:

* ALL compounds
* CHIRAL compounds
* NON-CHIRAL compounds

The final compound-level partition contains:

* 52,660 training compounds
* 13,165 test compounds

No compound overlap exists between the training and test partitions.

## Enantiomer sensitivity analysis

The repository includes an analysis of enantiomeric pairs whose members were assigned to different data partitions.

This analysis was used to assess the sensitivity of the predictive results to the treatment of enantiomeric compounds across the training and test sets.

The corresponding datasets, summary tables, results, and figures are provided in:

```text
enantiomer_analysis/
```

## ECFP4-Chiral benchmark

To provide a direct empirical comparison with a commonly used circular molecular fingerprint representation, the repository includes an **ECFP4-Chiral Random Forest benchmark**.

The ECFP4 representation was generated using a Morgan fingerprint with:

* Radius: 2
* Fingerprint size: 2048 bits
* Chirality information: included

The comparison uses the same compound-level partitioning strategy and a common test set.

The benchmark results are available in:

```text
ecfp4_chiral_benchmark/
```

The comparison includes predictive performance metrics such as:

* Accuracy
* Balanced Accuracy
* Precision
* Recall
* F1 score
* Matthews correlation coefficient (MCC)
* AUROC
* AUPRC

Prediction-time measurements are also provided for the common test set.
